## Sobre mí

Soy estudiante de Ingeniería Informática con especial interés en crear aplicaciones web, productos SaaS y herramientas digitales que resuelvan problemas reales.

Me gusta trabajar en proyectos completos: desde la idea, el diseño y la experiencia de usuario hasta el backend, la base de datos, el despliegue y la mejora continua del producto.

Actualmente estoy centrado en:

- Desarrollo full-stack con Next.js, React y TypeScript
- Backend y bases de datos con Supabase y PostgreSQL
- Automatización e integración de inteligencia artificial
- Arquitectura de software y experiencia de usuario
- Creación de productos digitales para empresas y usuarios
